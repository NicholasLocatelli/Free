# Security policy

L'app gestisce dati personali molto sensibili (comportamenti di dipendenza). La sicurezza e la
privacy sono priorità 1–2 nella gerarchia decisionale del progetto (`docs/AGENTS.md`).

## Segnalare una vulnerabilità

Non aprire issue pubbliche. Usa le
[GitHub Security Advisories](https://github.com/nicholaslocatelli/free/security/advisories/new)
del repository. Riceverai una risposta il prima possibile.

## Modello di sicurezza

Vedi [docs/architecture/security.md](docs/architecture/security.md): dati local-first, nessun
account obbligatorio, nessun analytics con contenuti sensibili, cancellazione completa dei dati
dall'app.
